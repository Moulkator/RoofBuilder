ROOF BUILDER

1.2.1
NEW:
- Added Cap Corners Style (Square / Round / Flat) and Cap Corners Length: hips end in a point, a half circle or a flat cut at the shape's corners, past the outline or short of it
- Added Ridge Ends (Mitred Faded / Round) and Ridge Fade slider: cross-faded joints (0% for a hard cut), or the ridge laid over the hips, ending in a half circle
- Added Cap Recolor button: shows Cap Brightness, Cap Hue and Cap Saturation
 
CHANGED:
- Improved corners on non-seamless textures: Line seams and Ridge Caps run on to the real corner.
- Improved Roof Pieces round ends: real half circles, with a dark line as thick as the strip's own.
- Moved the Ridge Caps cog to the right of the Seams menu. Cap Corners Length and Ridge Fade have their own cogs.


1.2.0
NEW:
- Added Auto Roof Library: while Roof Builder is on, the pattern list only shows roofs, including the Roof Tool's textures
- Added Roof Pieces Cap Style: Roof Tool textures use their own ridge and hip strips as Ridge Caps
- Added Cap Hue and Cap Saturation sliders
- Added Link buttons next to Tile Width and Pitch: they move together so the tiles keep their shape
- Added Copy Settings / Paste Settings buttons in the Select Tool (all settings but the texture)

CHANGED:
- Improved Cap Brightness: wider range both ways.
- Improved Side Lines: the outline now also runs over the Ridge Caps.
- Improved Roof Pieces: soft shadow around the strips, short fade where they meet.
- Improved icons: smoother when shrunk.


1.1.1
NEW:
- Added Profile for Centered roofs: Cone / Dome / Low Dome / Spire / Onion, also in the Pattern Tool + Curve slider

CHANGED:
- Improved shading: darker shadowed side on Centered, Hip and Gap Free Two Slopes.
- Improved performance: faster texture analysis (kept between sessions), roof shader loaded at start.

FIXED:
- Fixed roofs not working on the plain colour pattern (X Pattern)


1.1.0
NEW:
- Added Round Ends for Gap Free in Two Slopes mode
- Added Ridge Caps (Hip, Gap Free with Two Slopes): caps made from the roof texture, with mitred joints. None on valleys or curved outlines
- Added Seams menu (replaces Softer Seams): None / Line / Soft / Ridge Caps. Ridge Caps settings: Style, Width, Brightness, Outline
- Added Repeat Point: moves where the texture repeats
- Added Pitch on Gap Free roofs
- Added Merge With Roof Below button in the Pattern Tool

CHANGED:
- Added various settings buttons (cog icons): Ridge Caps (next to Seams), Texture Settings, Merge (Merge Height, junction line, valley shadow).
- Improved merged roofs: thinner junction line, valley shadow on both roofs.
- Added more Merge Height: -1000 to +1000 px.
- Pattern Tool settings reset when a map is opened.

FIXED:
- Fixed Side lines too thick on textures without tile rows (hay, thatch...)
- Fixed Roof Builder section missing with Minor Utils
- Fixed Pattern Tool settings not resetting when a map is opened
